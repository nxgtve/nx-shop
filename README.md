# NX's Shop — Product & Price List

A simple command-line CRUD application built with Python for managing products and their prices.

## Features

- Add products
- View all products
- Update product prices
- Delete products
- Search for products
- Validate product names
- Validate numeric and non-negative prices
- Handle invalid user input

## Technologies

- Python 3
- Lists
- Loops
- Conditional statements
- Exception handling
- String manipulation

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/nx-shop.git
```

2. Enter the project directory:

```bash
cd nx-shop
```

3. Run the program:

```bash
python3 main.py
```
